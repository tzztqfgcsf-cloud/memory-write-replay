# 정정 특이성 자료 작성 카드

- 작성 범위: 2026-09-27 신규 한국어 합성 대화 24사례, 12쌍의 탐색적 자료. 부정, 타인 대상, 시간 범위, 가정, 타인 말 인용, 전사 대안 간 핵심 불일치의 6계열에서 각 2쌍을 작성했다.
- 각 쌍의 긍정·부정 사례는 같은 기존 `f1` 기록과 같은 이전 대화 지시를 사용한다. 공개 history는 현재 항목만 편집하고 타인·다른 시점 정보는 새로 저장하지 않도록 범위를 제한한다. 과업은 현재 `f1` 한 항목의 유지 또는 동일 ID 값 정정뿐이다. 다른 사람이나 다른 시점 정보를 추가 저장하지 않는다.
- `public.json`은 입력만 포함한다. `reference.json`의 라벨·기대값·작성 이유는 모델 입력에서 분리해야 한다. `unsupported`는 기존 값 유지 또는 불확실성으로 인한 보류를 포함한다.
- 출처: AI가 새로 작성한 텍스트와 AI 작성 참조. 실제 음성, 실제 ASR 출력, 사용자 의도 라벨, 독립 사람 gold가 아니다. 전사 대안은 텍스트 조건을 모사한 것이며 음향 오류 빈도를 대표하지 않는다.
- 사용 한계: 이 자료로 모델의 실제 시니어 음성 효용, 기억 품질 일반화, 인간 합의율을 주장할 수 없다. 기존 동결 평가나 점수에 소급 적용하지 않는다.
- 작성 중 모델 추론·학습 호출: 0. 기존 모델 출력·점수·정책 코드는 열지 않았다.
